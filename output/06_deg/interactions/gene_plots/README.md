# Individual Gene Expression Plots

This directory contains individual expression plots for 88 genes showing significant interaction effects between PVC leachate treatment and developmental stage in *Montipora capitata* embryos.

## Overview

Each plot shows:
- Gene expression levels across different developmental stages
- Response to different PVC leachate concentrations (0%, 2.5%, 5%, 10%)
- Interaction patterns between stage and treatment
