# Goals

Download, check file integrity, and unzip genome reference files to our
`input/genome` directory.

## Inputs

- none

## Outputs

- Montipora_capitata_HIv3.assembly.fasta

  - `../../input/genome/Montipora_capitata_HIv3.assembly.fasta`

- Montipora_capitata_HIv3.genes_fixed.gff3

  - `../../input/genome/Montipora_capitata_HIv3.genes_fixed.gff3`

# Get reference genome files

This code grabs the *Montipora capitata* fasta file (rna.fna) of genes.

``` bash
# change to work in data directory
cd ../../input/genome
wget http://cyanophora.rutgers.edu/montipora/Montipora_capitata_HIv3.assembly.fasta.gz
```

## GFF

[`Montipora_capitata_HIv3.genes.gff3`](https://owl.fish.washington.edu/halfshell/genomic-databank/Montipora_capitata_HIv3.genes.gff3)
(67MB)

- MD5 checksum: `5f6b80ba2885471c8c1534932ccb7e84`

Obtain `Montipora_capitata_HIv3.genes_fixed.gff3` file by downloading
from GitHub.

``` bash
cd ../../input/genome
wget https://github.com/AHuffmyer/EarlyLifeHistory_Energetics/raw/master/Mcap2020/Data/TagSeq/Montipora_capitata_HIv3.genes_fixed.gff3.gz
```

This was generated by running the original gff file
`Montipora_capitata_HIv3.genes.gff3.gz` through this script in R:
<https://github.com/AHuffmyer/EarlyLifeHistory_Energetics/blob/master/Mcap2020/Scripts/TagSeq/Genome_V3/fix_gff_format.Rmd>

Unzip gff and genome file

``` bash
cd ../../input/genome
gunzip Montipora_capitata_HIv3.genes_fixed.gff3.gz
gunzip Montipora_capitata_HIv3.assembly.fasta.gz
```

## Checkout genome GFF format

``` bash
cd ../../input/genome
md5sum *Montipora_capitata*
```

``` bash
cd ../../input/genome
head -10 Montipora_capitata_HIv3.genes_fixed.gff3
```
